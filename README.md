# framemime

Frame HTML/Markdown mime fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/framemime/

## Install / run

```bash
git clone https://github.com/theworker02/framemime.git
cd framemime
node src/cli.js
node --test
```
